# it-courses

Сайт образовательной платформы «CodeStart».

## Что использовал
- HTML: семантическая верстка, формы
- CSS: Flexbox, сетка, тени, градиенты
- CSS: типографика, эффекты при наведении (`:hover`)

## Особенности проекта
- Темная тема в стиле IT
- Главный экран с ярким акцентом
- Программы обучения в виде карточек
- Блок с отзывами студентов
- Форма для записи на курс
